# Visual system
Horizontal 4×2 panel. Settings dropdown: Opaque (solid charcoal, default), Transparent (translucent charcoal glass), Opaque Smoky (original LRan hover shader over #111), Transparent Smoky (the same shader with alpha over translucent charcoal glass). Choice persists on the device and applies to the widget and preview. Left: four signal bars, TIM or connection status. Ring is green on validated mobile data, blue on validated Wi-Fi/other internet transport, red without validated internet. Right: used amount and GB on one baseline, “usados de 28,0 GB” beneath, remaining balance separated below. All numbers have one decimal and a Portuguese comma. No daily-average or update-time footer. A subtle vertical rule separates the groups. Canvas 720×320, fit-center on resize. No fixture values or PC-sourced data. Offline state preserves the last valid balance. Tapping any part opens ash-widgets.

Eight ViewFlipper frames animate signal opacity at 180 ms intervals without network queries or app process wakeups. The app preview renders Smoky live. ash-widgets opens as a native catalog with Internet TIM as the first registered widget type. Controls are at least 52 dp tall; captions use pale blue against navy. The connection flow stores credentials encrypted locally and uses the official TIM login page. Data capture interval: one hour, subject to Android scheduling.

Smoky source: LRan's Smoky Button on 21st.dev; see android/SMOKY.md for provenance and renderer details. App preview uses live TextureView/EGL driven by display vsync. The launcher receives 240 cached 160x71 background frames at a requested 16 ms interval, plus a sharp 720x320 foreground. Forty overlapping tail/head samples smooth the repeating loop. Widget cadence remains launcher dependent. Transparent variants use translucent navy gradients to simulate frosted glass, without claiming access to wallpaper backdrop blur. Viewport dimensions follow the real EGL surface after layout changes.

A specialUse foreground service keeps default-network callbacks alive while a widget is installed, without traffic capture, polling or wake locks. Android exposes its ongoing connection notification/task. Removing the final widget stops the service. TIM polling remains hourly. Android/OEM restrictions or force-stop can still suspend updates.

Smoky settings expose a native HSV color picker only when Smoky is selected, with hexadecimal input, Cancel, Apply and Restore blue. Applying persists smokyColor and rebuilds the shader cache using that primary color. The same color replaces the blue Wi-Fi arc while Smoky is active; green mobile and red offline retain their status meanings. GPU preparation happens on a worker and does not run for every drag event. Cache is keyed by color and opacity mode. The loop overlaps forty tail/head samples with smoothstep blending so its boundary continues into the next forward-time sample, rather than jumping or reversing.

Floating bottom dock: Home (catalog, widget preview, add/update), Customização (theme/color controls), Outros (only one centered “Em desenvolvimento” label), Login (account and authentication). Authored 24-unit outline icons share a 1.8-unit rounded stroke. Selected tab has a pale blue icon, bold caption and muted blue capsule. The charcoal dock is 72 dp tall with 20 dp side margins, 16 dp bottom clearance and elevation. Each target is 60 dp high; content scrolls independently with 104 dp bottom clearance. Tab selection survives activity recreation. Late background refresh/color callbacks must not switch the selected tab or restart a hidden preview.

Shader precision correction: runtime source uses highp float when the GPU supports it. The tested GPU reports 10 mantissa bits for mediump versus 23 for highp. The source's sine hash and multi-octave noise need the extra precision to avoid coarse dark patches. Raw shader equations and source file remain unchanged; precision promotion happens only in the Android adapter.


The HSV picker uses the same navy surface, rounded corners, pale blue accents and 52 dp actions as the app menu. A color swatch accompanies the hex field; Cancel discards edits, Apply validates hex, Restore blue restores the original shader primary.


Launcher identity: authored adaptive vector A, small pale blue widget tile and usage ring on navy; monochrome themed layer included. Smoky launcher frames use a native per-image rounded outline at 14 dp; adjustViewBounds and centered placement preserve card proportions and align the foreground. Corners are not baked into animation pixels.


App preview pager: Home and Customization share WidgetPreview. Vertical swipes alternate TIM data and a centered Em desenvolvimento label over the stationary themed background. Translation uses easeOutQuart over 120 ms; alpha uses easeOutQuart over 160 ms. Selection survives refresh. The launcher widget shows only the TIM card, without paging.
